# 人工智慧於醫學影像組學的分析與應用

## 課程核心簡介

本課程以實際醫學研究問題為起點，串聯醫學影像基礎、Radiomics、機器學習、深度學習、
Foundation Model 與多模態資料整合。學生會在每週實作中逐步建立自己的研究專題，從資料整理、
品質控制與影像前處理，一路完成特徵萃取、模型驗證、結果解釋及成果交付。

課程重點不是追求單一最高效能，而是建立具備以下特性的研究流程：

- **可重現**：他人能依說明重建環境、執行程式並得到一致的主要結果。
- **可驗證**：AI 產生的程式、引用、統計分析與圖表均經人工查核。
- **無資料洩漏**：前處理、特徵選擇及調參都在正確的資料切分內完成。
- **具臨床意義**：模型除了區辨能力，也評估校準、不確定性及實際效益。
- **符合研究倫理**：醫療資料完成去識別化，並遵守授權、IRB 與機構規範。
- **可交付**：程式、參數、資料流向、結果及 AI 使用方式均有完整紀錄。

本課程的最終判準：

> 把專案交給另一位研究者，對方不需詢問即可執行，並得到相同的主要結果與研究結論。

## 每週實作項目

### W02｜Radiomics 與影像 AI 研究評讀

- 繪製 Radiomics 五步驟研究流程。
- 比較手工特徵、CNN 與 Foundation Model 的適用情境。
- 使用簡化 RQS 檢核表評讀研究。
- 寫下暫定臨床問題、可取得資料及專題方向。

### W03｜AI 研究環境建置

- 在 Colab 驗證 GPU、掛載 Drive 並建立 `ROOT`。
- 安裝鎖定版本的套件，設定隨機種子並輸出環境紀錄。
- 建立標準專案資料夾與檔案命名規則。
- 校準 Gemini，並以 Cursor 開啟完整專案資料夾。
- 完成版本、路徑及隨機性的除錯挑戰。

實作教材：[`notebooks/W03/Readme.md`](notebooks/W03/Readme.md)

### W04｜醫學影像基礎與資料健檢

- 讀取 DICOM metadata 並整理成資料表。
- 盤點影像模態、體素間距、切片厚度、重建條件及掃描參數。
- 製作資料健檢卡，判斷資料是否適合進行 Radiomics。
- 列出自身資料的主要風險及處理方式。

### W05｜文獻回顧與研究假說

- 使用 PubMed、MeSH 與布林運算建立可重跑的檢索式。
- 查核 AI 提供引用的 DOI、書目資料與原文結論。
- 以 PICO／FINER 整理研究問題。
- 產生一個可被資料否證的研究假說。

### W06｜AI 輔助 Radiomics 程式開發

- 檢查影像與遮罩的尺寸、間距、原點、方向及標籤。
- 找出不會產生錯誤訊息的靜默錯誤。
- 將前處理與特徵萃取參數移至 YAML 設定檔。
- 與同學交換腳本，進行程式碼與輸出驗證。
- 建立已知答案的小型測試案例。

### W07｜影像資料整理與品質控制

- 建立資料 manifest 與納入／排除紀錄。
- 稽核資料授權、完整性、metadata、影像品質及期相。
- 檢查 DICOM header、private tags 與影像中的燒錄文字。
- 檢查病人重複、中心差異及設備批次效應。
- 製作資料流失圖並記錄每一例的處理決策。

### W08｜影像前處理與自動化

- 比較重取樣前後的影像、遮罩及 ROI 體積。
- 實作強度正規化與灰階離散化。
- 比較濾波、離散化參數及處理順序對特徵的影響。
- 建立可由設定檔控制的前處理 pipeline。
- 輸出執行日誌、成功例數、失敗原因及方法段落。

### W09｜統計分析與論文圖表

- 建立包含遺漏值處理規則的 Table 1。
- 以已知答案驗算 AI 產生的統計程式。
- 執行多重比較校正。
- 報告 AUC、校準、Brier score、決策曲線及信賴區間。
- 將誤導圖表改造成可投稿且資訊完整的版本。

### W10｜機器學習與 AutoML

- 依研究問題選擇分類、迴歸或存活分析流程。
- 建立 LASSO 或其他正規化線性基準模型。
- 繪製資料切分、前處理、特徵選擇及調參流程圖。
- 使用交叉驗證比較模型並報告摺間變異。
- 檢查病人重複、切分前特徵選擇及測試集調參等洩漏。
- 完成期中研究計畫書與 RQS 自評。

### W11｜AI 輔助影像分割

- 使用點、框或混合提示產生初始分割。
- 建立分割結果的收件、修正與退件規則。
- 計算 Dice、HD95 及體積誤差。
- 依病灶大小與影像品質分層檢視結果。
- 保存提示、人工修訂、排除及抽樣盲審紀錄。

### W12｜Radiomics 特徵萃取與解釋

- 手算小型 GLCM 並核對程式輸出。
- 使用完整參數檔萃取 Radiomics 特徵。
- 找出高度相關特徵並進行分群或降維。
- 比較 SHAP、permutation importance 與模型係數。
- 撰寫不過度推論生物機制的特徵解釋。

### W13｜特徵選擇與假說驗證

- 比較 filter、wrapper 與 embedded 特徵選擇。
- 將特徵選擇放入巢狀交叉驗證內。
- 以重複子抽樣計算特徵選擇頻率。
- 區分事前假說與事後探索結果。
- 繪製可避免資料洩漏的完整特徵選擇流程。

### W14｜梯度提升臨床預測模型

- 在相同資料切分上建立線性基準。
- 比較 XGBoost、LightGBM 與 CatBoost。
- 在訓練摺內執行早停及有限次數調參。
- 保存搜尋空間、所有嘗試、參數、種子及套件版本。
- 比較模型效能、校準及不確定性並說明選型理由。

### W15｜Deep Learning Radiomics 與 Vision Transformer

- 比較手工、深度與混合特徵。
- 計算 CNN 感受野與 ViT token／注意力成本。
- 使用公開預訓練模型萃取深度特徵。
- 將深度特徵接入既有特徵選擇與驗證流程。
- 與手工特徵基準比較 AUC 及信賴區間。
- 說明採用或不採用深度學習的資料條件。

### W16｜多模態 AI 資料整合

- 建立只使用臨床資料的基準模型。
- 製作模態、取得時間點及缺失率資料表。
- 比較影像、電子病歷及生物標記的增量效益。
- 實作 early、intermediate 或 late fusion。
- 移除決策時點後才產生的欄位。
- 評估缺失機制、送檢偏差及跨平台批次效應。

### W17｜研究成果口頭報告

- 在限定時間內呈現研究問題、資料、方法、結果及限制。
- 清楚標示資料切分、特徵選擇及測試集使用方式。
- 報告比較基準、信賴區間、校準與主要失敗結果。
- 進行同儕互評與問答。
- 記錄教師回饋、同儕建議及自我檢查各一項修改。

### W18｜專題成果與可重現性驗收

- 在乾淨環境中依 README 從頭執行專案。
- 與同學交換專案並記錄第一個錯誤及修補方式。
- 比對程式輸出、圖表與口頭報告中的結果。
- 繳交程式碼、環境檔、特徵矩陣、模型結果及產圖程式。
- 繳交可重現說明、AI 使用聲明及修改完成紀錄。
- 完成研究品質自評並列出投稿前仍需補強的項目。
