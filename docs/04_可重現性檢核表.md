# 數字對不起來的六個來源

> 「跑得動」跟「跑得出一樣的數字」是兩件事，距離比你以為的遠。
> W18 專題驗收的方式就是後者：我拿你的檔案、照你的說明跑一次，看能不能得到你報告裡的數字。

| 來源 | 具體表現 | 對策 | 哪一週處理 |
|---|---|---|---|
| 套件版本 | 特徵定義或預設參數在版本間改變 | 鎖定版本、輸出 requirements | W03（今天） |
| 隨機性 | 切分、初始化、取樣每次不同 | 全域設定種子並記錄 | W03（今天） |
| 路徑與資料 | 路徑寫死、資料被人改過 | `ROOT` 變數、資料版本標記 | W03（今天） |
| 前處理參數 | 重取樣、離散化 bin 數未記錄 | 參數集中管理並輸出 | W08 |
| 硬體與平行 | GPU 型號、浮點運算順序差異 | 記錄硬體，必要時關閉不確定性 | W14 |
| 流程順序 | 特徵選擇在切分之前做 | 固定流程、寫成腳本 | W13 |
